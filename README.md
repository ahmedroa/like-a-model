# Like A Model — الموقع التعريفي

صفحة هبوط (Landing Page) عربية بالكامل، RTL، بدون أي أدوات بناء.
افتحي `index.html` مباشرة في المتصفح — هذا كل شيء.

```
Like A Model/
├── index.html              ← الصفحة (١٥ قسمًا)
├── assets/
│   ├── css/styles.css      ← نظام التصميم كاملًا
│   ├── js/main.js          ← الإعدادات + التفاعل
│   └── img/                ← صور مؤقتة (SVG)
├── desgin.md               ← مرجع UI/UX
└── README.md
```

---

## ✏️ ما يجب تعديله قبل النشر

كل ما يحتاج تعديلًا موجود في **أعلى ملف [assets/js/main.js](assets/js/main.js)** — كتلتان فقط:

### ① بيانات التواصل

```js
const CONTACT = {
  whatsapp : '966500000000',            // بصيغة دولية بدون + أو مسافات
  phoneText: '+966 50 000 0000',
  email    : 'hello@likeamodel.sa',
  instagram: 'https://instagram.com/',
  address  : 'الرياض — المملكة العربية السعودية'
};
```

هذه القيم تُحدِّث تلقائيًا: زر واتساب العائم، أزرار الـCTA، الفوتر،
ورابط «أرسلي رحلتك» في قسم *ابني رحلتك*.

### ② الأسعار

```js
const PRICING = { ems: null, pt: null, reformer: null };
```

- `null` → يظهر **«عند الطلب»** (الوضع الحالي)
- رقم مثل `1200` → يظهر **«١٬٢٠٠ ريال»**

> الأسعار الفعلية لم تُدرَج لأنها لم تُرفق مع المحتوى. ضعيها هنا متى ما جهزت.

## 🖼️ الصور

الصور الحالية **مؤقتة (SVG)** ومصمَّمة لتبدو مقصودة حتى تستبدليها.
استبدلي الملف بنفس الاسم أو بدّلي المسار في `index.html`:

| الملف | المكان | النسبة المطلوبة |
|---|---|---|
| `assets/img/hero-portrait.svg` | الواجهة الرئيسية | **3:4** رأسية |
| `assets/img/result-before.svg` | قسم النتائج — قبل | **4:5** |
| `assets/img/result-after.svg` | قسم النتائج — بعد | **4:5** |
| `assets/img/og-cover.svg` | صورة المشاركة | **1200×630** |
| `assets/img/favicon.svg` | أيقونة التبويب | مربّعة |

**للأداء:** استخدمي `.webp` بدل `.jpg` عند الاستبدال، واحتفظي بخاصيتَي
`width` و`height` في وسم `<img>` كما هي حتى لا تقفز الصفحة أثناء التحميل.

> ⚠️ صور «قبل / بعد» تُنشر بإذن كتابي من العميلة فقط.

## 💬 آراء العميلات

الآراء الثلاثة في قسم النتائج **نماذج توضيحية** وعليها تعليق واضح في
`index.html` (ابحثي عن `✳️ نماذج توضيحية`). استبدليها بآراء حقيقية
قبل النشر — أو احذفي الكتلة بالكامل.

## 🎨 الألوان — سطر واحد

الألوان كلها متغيّرات CSS في أول [assets/css/styles.css](assets/css/styles.css)
ضمن `:root`. البالتة هي **«روز نوار»** نفسها المستخدمة في تطبيق العميلات،
لضمان تطابق الهوية بين الموقع والتطبيق.

| الدور | القيمة |
|---|---|
| `--primary` | `#9B3B67` |
| `--deep` | `#5C1F3D` |
| `--gold` | `#C9A46A` (زينة فقط) |
| `--gold-text` | `#8A6428` (الذهبي الصالح للنصوص) |
| `--bg` | `#FFFBFC` |

> **لا تستخدمي `--gold` لنص على خلفية فاتحة** — تباينه 2.3:1 فقط.
> استخدمي `--gold-text` بدلًا منه.

## ⚙️ ما هو مبني بالفعل

- **ابني رحلتك** — أربع خطوات تفاعلية (هدف / أسلوب تدريب / مدة / مستوى)
  مع بطاقة ملخّص حيّة، وشريط تقدّم، وزر يرسل اختيارات العميلة إلى واتساب
  كرسالة جاهزة.
- **الأسئلة الشائعة** — `<details>` أصلية تعمل بدون JavaScript، ويضيف
  الـJS سلوك «سؤال واحد مفتوح».
- **قائمة الجوال** — مع حصر التركيز (focus trap) وإغلاق بـ `Esc`.
- **تظليل رابط القسم الحالي** أثناء التمرير.
- **زر المشاركة** — Web Share API مع نسخ الرابط كبديل.
- **حركات الظهور** — تتوقف تلقائيًا مع `prefers-reduced-motion`.

## ♿ إمكانية الوصول

- تباين نصوص **AA (4.5:1)** في الوضعين الفاتح والداكن.
- حلقة تركيز ظاهرة على كل عنصر تفاعلي — لم تُزَل من أي مكان.
- أقل مساحة لمس **48×48px**.
- أيقونات **SVG** فقط (لا إيموجي كأيقونات).
- روابط تخطّي، و`aria-live` لتحديثات الملخّص، و`lang="ar" dir="rtl"`.
- الصفحة تعمل كاملة بدون JavaScript (عدا التفاعلات الإضافية).
